# Notepad

Это обычный текстовый редактор на Qt с базовыми возможностями из лаб 5-8 и дополнительными функциями.

## Что реализовано

### 1) Обработка ошибок (required)
Добавлены пользовательские исключения для файловых операций:
- файл не найден,
- ошибка чтения,
- ошибка записи.

Если при `Open` или `Save` возникает проблема, показывается окно с заголовком `Error` и текстом ошибки.

### 2) Spell Checker (required)
Проверка орфографии работает на словаре `data/words.txt`.

Как использовать:
1. Просто печатай текст в редакторе.
2. Слова с ошибкой подчеркиваются красной волнистой линией автоматически.
3. Нажми правой кнопкой по слову с ошибкой, чтобы увидеть варианты замены (до 5).
4. Выбери вариант из меню, слово заменится.
5. Если нужно обновить проверку вручную: `Tools -> Check Spelling...`.

### 3) Optional feature: Cursor line / column indicator
В статус-баре снизу показывается:
- количество слов (`Words`),
- количество строк (`Lines`),
- текущая строка курсора (`Current_Line`),
- текущая колонка курсора (`Column`).

Ничего включать не нужно, обновляется автоматически при наборе и перемещении курсора.

### 4) Optional feature: Font dialog
Меню: `Format -> Font...`

Как использовать:
1. Выдели текст (или не выделяй, чтобы применить ко всему документу).
2. Открой `Format -> Font...`.
3. Выбери шрифт и нажми `OK`.

### 5) Optional feature: Zoom
Меню: `View`
- `Zoom In` (`Ctrl + +`)
- `Zoom Out` (`Ctrl + -`)
- `Reset Zoom` (`Ctrl + 0`)

Как использовать:
- Меняй масштаб через меню `View` или горячими клавишами.
- `Reset Zoom` возвращает стандартный масштаб.
